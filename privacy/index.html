02 / App 内的照片处理

菲林胶片集在设备上读取所选照片或 RAW，进行预览、调色和导出。它会处理图像内容，以及读取和编辑所需的文件、照片标识与元数据。照片可能包含人物、位置或其他个人信息；本地处理不等于没有处理个人信息。当前版本没有自建上传服务，也没有自动向开发者上传照片、RAW、项目或诊断文件的功能。

03 / Photos、Files 与 iCloud

自定义图库按系统授权访问 Photos。系统照片选择器按用户选择交付内容；Files 导入访问用户选定的文件。读取不在设备上的 Photos 原片可能由系统从 iCloud 下载；Files 服务提供方也可能从云端提供文件。导出到 Photos 的照片可能随用户的系统设置同步。系统备份也可能包含 App 的本地数据。

这些系统或文件提供方的数据流与开发者自建上传服务不同，取决于您的权限、同步、备份及服务设置。您可在系统设置中调整权限。菲林胶片集不保证完全不联网，也不保证所有数据始终只存在当前设备。

04 / 本地项目、来源与缓存

为继续编辑，App 在本地保存项目、调色参数、工作与批次记录、缩略图、导入的 User LUT、Recipe 与偏好。来源可能是 Photos 中的照片标识，也可能是 App 自有目录中的托管副本；托管副本不是向开发者上传。RAW 缩略图用于浏览；分类缓存保存识别所需的照片标识、版本或修改信息、尺寸和类型等。读取与导出过程中还可能产生临时文件。

托管原片可能保留原有 EXIF 等元数据。不要假设所有元数据都已去除。未托管的外部来源可能在访问权限或提供方状态变化后需要重新选择。

05 / 工作保留与删除

完成工作的保留选项为 1 天、7 天、30 天或永久。已有有效设置优先；没有有效设置时才默认 7 天。自动到期清理针对全部正式成员已成功导出、没有待完成导入、当前非活动且已到期的工作，从完成导出计算，而不是从导入时间计算；删除前会重新检查项目状态。未完成草稿和活动工作不适用这一笼统的 7 天期限。

手动删除工作会移除工作记录及其独占项目，并尝试删除派生缩略图；这一操作保守保留托管来源。到期清理还会在引用安全检查后尝试释放 App 自有托管副本。存在其他引用、读取不完整或清理失败时，副本可能保留并等待重试。

“永久”阻止新的按期限到期删除，但不会撤回先前已记录的删除与副本清理。此规则不删除系统 Photos 原片、外部原文件或共享 User LUT。缓存、临时文件、系统备份及已发给第三方的副本有不同生命周期，不承诺所有数据立即永久删除。

06 / 主动导出、分享与剪贴板

您决定是否导出照片、分享或复制 Recipe，以及向谁发送。Recipe Code 包含名称与调色设置等，不包含照片本身，也不内嵌用户导入的 LUT 文件。系统分享、剪贴板同步和接收方服务可能进一步处理您主动提交的内容；提交前请检查内容和接收方。

07 / TestFlight 测试与反馈

测试问题优先通过 TestFlight 内置反馈提交。Apple 的 TestFlight 服务会收集并向开发者提供测试安装、使用、设备与崩溃资料；主动反馈还可能包含截图、评论和关联技术信息。是否显示邮箱等与邀请方式及提交内容有关。这与菲林胶片集未集成第三方行为统计或自动崩溃 SDK 是不同的事实。

发布者本人为排查和改进 App 查看必要资料，不默认批量导出全部反馈。Apple 对平台数据有独立保留规则；Apple 说明测试反馈保留一年，崩溃与使用资料可能保留至问题解决。开发者另存副本按下文期限处理。详见 TestFlight 与隐私。

08 / 邮件支持与自愿附件

日常支持请联系 634989219@qq.com。发送邮件会把您的邮件地址、正文、往来内容以及您自愿附加的截图、样片或诊断文件交给发布者，并经您所用的邮件服务和收件方 QQ 邮箱处理。支持邮箱由发布者本人使用，不同步到其他服务；QQ 邮箱本身仍会处理和存储邮件。网站邮件链接只打开您的邮件应用，不会自行发送邮件或附加照片。

请先提供版本、设备、系统与复现步骤。截图、RAW 或其他样片均为自愿；不需要完整图库。请使用您有权分享的最小样本，去除不必要的人物、位置、账号及其他敏感内容。原片可能带有 EXIF。不会自动读取诊断文件，也不把反馈、样片或诊断上传至公开工单或第三方 AI 服务。QQ 邮箱及发送方服务的存储、日志和备份由各自规则管理，不能由 App 删除操作代替。

09 / 支持资料保留与请求

按单人运营规则：可识别的邮件、普通截图与必要反馈记录，在问题关闭后最多保留 90 天；尚未关闭且连续 180 天没有实质往来的问题，结束处理并清理相关记录。每 90 天复查未解决事项。

自愿提供的 RAW、原片、项目或详细诊断副本，在完成分析后 30 天内删除，并且不晚于收到后 90 天；继续需要时另行征得用户同意。仅在确已去除联系人、图片和可识别信息时，可保留不含个人信息的缺陷摘要用于回归。资料仅供发布者本人支持和排障使用，访问人员变化前更新安排。

可通过支持邮箱请求查询、更正或删除开发者持有的支持资料，或撤回自愿提供附件供后续使用的同意；撤回不影响此前已合法进行的处理。为定位记录，只核对必要的信息，不索取密码、验证码、私钥或完整图库。发布者清理可控邮箱、附件和本地副本；服务商备份、日志及依法必须保留的特定记录不能保证同时清除。必要例外应限量、说明原因并到期复查。

10 / 网站托管与访问日志

网站采用 GitHub Pages 托管。网站页面没有账号、后台、在线表单、统计或跟踪脚本、第三方字体 CDN，也未设置 Cookie 或本地存储。中英文分别通过静态地址访问，不会自动上传照片或诊断。

GitHub 说明，访问 GitHub Pages 时，访客 IP 地址会为安全目的被记录和保存，无论是否登录。网站没有统计脚本，不代表托管服务没有访问数据。GitHub 的安全日志及备份由其控制；本政策不为 GitHub 承诺具体保存期限。

参见 GitHub Pages 数据说明及 GitHub 隐私声明。

11 / 当前服务范围与政策更新

首轮 Beta 不使用广告、第三方行为统计、自建上传服务或自动崩溃上报 SDK。未来可能增加服务，但它们不属于当前发行候选。若数据用途、接收方、保留期限或服务发生变化，先评估实际数据流，更新中英文政策的日期与变更说明，并在适用时提供通知或取得必要同意，再启用相关处理。以实际启用的服务为准。
